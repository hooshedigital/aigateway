# Support

## Getting Help

There are several ways to get help with AI Gateway:

1. **Documentation**: Read the [docs/](docs/) folder for detailed guides.
2. **Search Issues**: Check [GitHub Issues](https://github.com/hooshedigital/aigateway/issues) for known problems.
3. **Create an Issue**: Use the appropriate issue template (bug report, feature request, or question).
4. **Email**: Contact us at [info@hooshedigital.ir](mailto:info@hooshedigital.ir).

## Response Times

| Priority | Description | Response Time |
|----------|-------------|---------------|
| Critical security | Security vulnerabilities | 48 hours |
| Bug reports | Confirmed bugs affecting functionality | 3-5 business days |
| Feature requests | New feature suggestions | 1-2 weeks |
| Questions | General questions about usage | 3-5 business days |

## Before You Ask

Before creating an issue or sending an email, please:

1. Read the [Troubleshooting Guide](docs/TROUBLESHOOTING.md).
2. Check the [API Reference](docs/API.md) for correct usage.
3. Search existing [GitHub Issues](https://github.com/hooshedigital/aigateway/issues) for similar problems.
4. Include your environment details (OS, browser, Node version, deployment method).

## Community

- **GitHub Issues**: For bug reports, feature requests, and questions.
- **Email**: For private or security-related matters.
- **Sponsors**: Support the project via [GitHub Sponsors](https://github.com/sponsors/hooshedigital).
